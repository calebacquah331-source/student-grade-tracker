Real-World Applications of Arrays

1. Introduction

An array is a data structure that stores a collection of related values under one variable name. Each element can be accessed by its position, called an index. Arrays help programs organise, access, and process multiple items.

2. Real-world applications of arrays

  • Student management: Store student names, IDs, marks, and grades to search results and calculate averages.
  • Banking: Keep transaction lists so users can review and search transaction histories.
  • Online shopping: Store shopping-cart products to add or remove items and calculate totals.
  • Hospital management: Organise patient details, appointments, and waiting lists.
  • Inventory management: Store products, prices, and quantities to monitor stock.
  • Weather forecasting: Store temperature or rainfall readings to calculate averages and identify trends.
  • Transport booking: Manage passenger lists, reservations, and seat availability.
  • Social media: Organise posts, comments, and notifications for display and processing.

3. Why arrays are necessary

  • Organisation: Keep related information together in one collection.
  • Access: Retrieve elements by index and search records using identifying values.
  • Processing: Process many records to calculate totals, averages, and maximum values.
  • Searching and sorting: Find matching records and arrange them in a useful order.
  • Flexible size: JavaScript arrays can grow or shrink as records are added or removed.

4. Developed application: Student Grade Tracker

This application stores student records containing a name, student ID, and score. Users can add, edit, search, sort, and delete records. It calculates the number of students, class average, highest score, and a letter grade for each score.

Example of a student record in JavaScript:

let students = [];

students.push({
  name: "Ama Mensah",
  id: "STU001",
  score: 86
});

5. How the application uses arrays

  • push() adds a student record.
  • find() locates a record for editing or deletion.
  • filter() finds matching records and removes selected records from the collection.
  • sort() arranges records by name, ID, or score.
  • reduce() adds scores to calculate the class average.
  • map() processes scores to help determine the highest result.

6. Conclusion

Arrays are important because they help applications store and process many related values in an organised way. The Student Grade Tracker demonstrates this by managing student records, searching and sorting results, and calculating class statistics. The entire project is contained in one index.html file with HTML, CSS, and JavaScript.

Note: Records are saved in the current browser on the current device. They are not automatically shared with other users or devices.
